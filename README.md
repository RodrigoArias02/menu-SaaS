# 🍴 Delivery App - React + Supabase

Aplicación web de delivery desarrollada con React y Supabase.

El proyecto permite:

- Mostrar productos por categorías
- Abrir modal de producto
- Agregar productos al carrito
- Modificar cantidades
- Eliminar productos
- Visualizar resumen del pedido
- Persistencia de datos con Supabase

---

# 🚀 Tecnologías utilizadas

- React
- Vite
- CSS3
- Supabase
- Font Awesome
